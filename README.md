# Pagina-Web
## Comparativa de Diseño: Propuesta vs. Sitio Oficial

Esta sección detalla las mejoras de Experiencia de Usuario (UX) e Interfaz (UI) implementadas en este proyecto en comparación con el sitio institucional actual de [Kinal](https://www.kinal.org.gt).

### Cuadro Comparativo

| Característica | Sitio Oficial (Tradicional) | Propuesta Actual    | Impacto en el Usuario |
| :--- | :--- | :--- | :--- |
| **Primer Impacto** | Sliders estáticos o imágenes fijas. | **Hero Video Fullscreen** con Overlay. | Inmersión inmediata y conexión emocional con el entorno educativo. |
| **Navegación de Programas** | Scroll vertical continuo y denso. | **GSAP Horizontal Scroll** | Reduce la carga cognitiva al enfocar un solo programa a la vez. |
| **Datos de Impacto** | Texto estático (cifras planas). | **Contadores animados** (Odómetro GSAP). | Gamificación de datos que transmite éxito y crecimiento dinámico. |
| **Estructura Visual** | Diseño de cuadrícula estándar. | **Glassmorphism & Layering** (Efecto .5). | Estética moderna que posiciona a Kinal como una institución tecnológica de vanguardia. |
| **Interactividad** | Botones básicos. | **AOS (Animate On Scroll)** y micro-interacciones. | Feedback visual constante que incentiva al usuario a seguir explorando. |

---

###  ¿Por qué esta propuesta es superior?

1.  **Storytelling Moderno:** Mientras que el sitio oficial funciona como un catálogo de información, este diseño funciona como una **narrativa visual**. El uso de GSAP para el scroll horizontal transforma la lectura en una experiencia guiada.
2.  **Psicología del Color y Espacio:** Se respeta la paleta institucional, pero se aplica con una jerarquía visual clara, utilizando espacios en blanco y efectos de desenfoque para mejorar la legibilidad.
3.  **Retención (Stickiness):** La implementación de bibliotecas como **Swiper.js** con profundidad de capas y **AOS** para la entrada de elementos asegura que el usuario permanezca más tiempo en el sitio por pura curiosidad visual.
4.  **Enfoque en Conversión:** El diseño de las tarjetas de blog y la sección de "Antiguos Alumnos" no solo informa, sino que invita a la acción mediante botones estilizados y una disposición visual que prioriza el contenido más relevante.
